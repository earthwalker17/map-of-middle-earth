# reference/ — dev-only visual references

Visual references for look-dev and QA comparison (`pnpm shots` / `pnpm qa`): canonical maps, film stills,
concept art, bigature/miniature photos, real-world photos and a LEGO MOC. **Dev use only — never shipped,
never redistributed.** Most items are copyrighted (Tolkien Estate / HarperCollins, New Line Cinema /
Warner Bros., the artists, Weta Workshop); a few Wikimedia Commons items carry CC / PD licences (credited
in `CREDITS.md`).

- **Binaries are gitignored.** Only this README and `manifest.json` are committed.
- `manifest.json` is the source of truth: path, source URL, request headers, what it shows, subject id,
  kind, source, licence, bytes, sha256 (sorted by kind → subject → file).
- **Restore / verify:** `pnpm refs:fetch` (`node tools/refs/fetch.mjs`) re-downloads missing or
  sha-mismatched files; `--check` only verifies; `--match <text>` filters by path. Items with `url: null`
  (the LEGO renders) cannot be downloaded — restore them from the user's originals.
- Geography source data (DEM, vectors) is not here: see `data/source/README.md` (`pnpm data:fetch`).

## Folder conventions

| Folder | Contents |
|---|---|
| `film/<id>/` | Film stills (LOTR / Hobbit trilogies), one folder per place id |
| `concept-art/<id>/` | Concept art & illustration (Alan Lee, John Howe, Ted Nasmith, Tolkien, film design) |
| `bigatures/<id>/` | Weta bigature / miniature photos (`general/` = not tied to one place) |
| `photos/<id>/` | Real-world photos: NZ filming-location look-alikes, relief models, dioramas (`general/`) |
| `maps/` | Canonical and fan maps (Christopher Tolkien, Pauline Baynes, Daniel Reeve, Commons) |
| `lego-moc/` | LEGO Middle-earth MOC renders supplied by the user (layout / readability reference) |

`<id>` is the kebab-case place id shared with `data/world/places.json`, landmarks and bookmarks
(`minas-tirith`, `helms-deep`, …); `general` = not tied to a single place.

**143 items:** maps 15 · film stills 65 · concept art 37 · bigatures 8 · photos 13 · LEGO renders 5.
Licence column omits the "dev reference only" suffix that applies to every © item.
