# README images

Renders made by this project's own renderer and encoded by `pnpm showcase` from `data/qa/showcase.json`.
`manifest.json` records, per image, the source render (run, shot id, render sha256), the size and a sha256.

**Not covered by the MIT licence in the root `LICENSE`, and no reuse licence is granted for them.** They
show terrain derived from the ME-DEM elevation model, the ME-GIS vector layers and the Arda packaging,
whose authors are credited in [`CREDITS.md`](../../CREDITS.md); they are here to illustrate the project.
They contain no film stills, artwork or reference images; the titles on `film-placeholder.jpg` and
`social-preview.jpg` are set in the OFL fonts Cinzel and Cormorant Garamond.
