# Research briefs (historical)

One-off research reports written at the start of the project (2026-09-28/29) to choose the stack, the data
and the look. They are kept as a record of the reasoning behind early decisions and are **not maintained**:
versions, URLs and proposals may be out of date, and some proposals were never built. The current contracts
live in [`../ARCHITECTURE.md`](../ARCHITECTURE.md) and the current state in
[`../PROJECT_STATE.md`](../PROJECT_STATE.md).

| Brief | Topic |
|---|---|
| [threejs-stack.md](threejs-stack.md) | three.js r186, WebGPURenderer + TSL, limits and pitfalls |
| [geography-data.md](geography-data.md) | ME-GIS / ME-DEM / Arda datasets, coordinates and terms |
| [capture-pipeline.md](capture-pipeline.md) | deterministic offline capture to video on Windows |
| [lookdev-route-typography.md](lookdev-route-typography.md) | film grading by region, cinematography, route line, typography |
| [landmarks-west-north.md](landmarks-west-north.md) · [landmarks-south-east.md](landmarks-south-east.md) | visual reference notes per landmark |
| [music-tooling.md](music-tooling.md) | tooling for an original code-generated score |

Film stills and artwork named in the landmark briefs are copyrighted by their owners and were used only as
private look-development reference; none of them is part of this repository or its renders.
